# TripFlow 통합 테스트 체크리스트

- 테스트 환경: Chromium 기반 브라우저, 로컬 서버(`python -m http.server`), 데스크톱(1400×900)과 모바일(375×812) 화면
- 결과: ✅ 통과 / ⬜ 미확인 (직접 확인 필요)

## 1. 여행 생성·관리

| # | 테스트 | 기대 결과 | 결과 |
|---|---|---|---|
| 1-1 | 종료일이 시작일보다 빠른 여행 생성 | "종료일은 시작일보다 빠를 수 없습니다" 경고, 생성 안 됨 | ✅ |
| 1-2 | 4일 여행 생성 | Day 1~4 탭 자동 생성 | ✅ |
| 1-3 | 여행 기간을 4일 → 3일로 수정 (일정 있는 날이 잘림) | 삭제될 일정 수를 알려주고 확인 후 'N일차' 기준으로 이동 | ✅ |
| 1-4 | 여행지 변경 | 지도 중심 좌표를 다시 찾음 | ✅ |
| 1-5 | 여행 삭제 | 하위 날짜별 일정까지 LocalStorage에서 함께 삭제 (연쇄 삭제) | ✅ |

## 4. 지도

| # | 테스트 | 기대 결과 | 결과 |
|---|---|---|---|
| 4-1 | 장소명으로 위치 검색 (예: Senso-ji) | 후보 목록 → 선택 → 좌표 저장, 마커 표시 | ✅ |
| 4-2 | '지도에서 선택' 후 지도 클릭 | 클릭한 좌표가 저장되고 선택 모드 종료 | ✅ |
| 4-3 | 위치 없는 장소 | 카드에 "위치 없음" 배지, 지도에서는 제외, 번호는 목록 순서 유지 | ✅ |
| 4-4 | 드래그로 순서 변경 | 마커 번호·경로선·이동시간이 함께 갱신 | ✅ |
| 4-5 | 카드에 마우스 올리기 / 마커 클릭 | 마커 강조 / 해당 카드로 스크롤·강조 | ✅ |
| 4-6 | 새 여행 생성 | 여행지 중심 좌표를 찾아 지도 기본 위치로 사용 | ✅ |
| 4-7 | 검색 결과 없음 / 네트워크 오류 / 요청 제한(429) | 안내 메시지, '지도에서 선택' 유도 | ⬜ (코드 경로만 구현, 직접 재현 필요) |
| 4-8 | 지도 라이브러리 로딩 실패 (오프라인) | 지도 영역에 안내 문구, 일정 관리는 계속 동작 | ⬜ |
